DNS / TXT RECORDS

    
Query the right name

    
A TXT record attaches text to a DNS name. At the root of my domain, I could see the assignment record and an SPF record in the same answer. GitHub’s verification record lived at a separate name, so I checked that name directly.

    
nslookup -type=TXT borasevgili.me. 8.8.8.8

    
Comparing a query to Namecheap’s authoritative nameserver with one to a public resolver helped me tell when a record had been published and when it was visible to others.

  

  

    
HTTPS / TLS

    
A valid certificate and a redirect are separate checks

    
After GitHub passed the DNS check, HTTPS started working while the Enforce HTTPS box was still unavailable. I could load the site over HTTPS before plain HTTP was configured to redirect.

    
I check the HTTPS URL directly for a browser certificate warning. I check the HTTP URL separately to see where it redirects. That distinction made the status messages in GitHub Pages easier to understand.
